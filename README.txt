OCSIMS – On Campus Students Interaction Management System

IMPORTANT: Upload the CONTENTS of this folder to the ROOT of your GitHub Pages repository.
Do not upload this folder as a nested directory. GitHub Pages needs index.html at the repository root.

Files:
- index.html: main website entry page
- style.css: all shared visual styling
- app.js: interactive features (routing, posts, listing, buying, login and registration)
- data.js: demo DBMS seed data
- assets/logo.svg: project logo
- login.html / register.html / dashboard.html / found.html / lost.html / sell.html / buy.html / about.html: direct page entry points

For a local test, extract this ZIP and open index.html (not README.txt) in Chrome.
The demo uses browser localStorage for persistence. Login and registration are demo-only; do not use real passwords.
